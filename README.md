# FELID

This is the implementation of FELID: A Flexible and Efficient Design for
Transformer Fine-Tuning over Encrypted Data.

## Structure

- [CPU_core](CPU_core/README.md): CPU implementation of the core algorithms and tests.
- [GPU_core](GPU_core/README.md): GPU implementation of the core algorithms and tests.
- [e2e_experiment_GPU](e2e_experiment_GPU/README.md): an end-to-end encrypted fine-tuning experiment.
- [Plaintext](Plaintext/README.md): continued pretraining for a kernel attention model.


## Getting started

```bash
git clone https://github.com/LWEpsilon-FHE/FELID.git
cd FELID
```
